# TableTop Nights

BBF 302E Database Systems Course Project (Fall 2026) - Team ASLANLAR

## About the Project
TableTop Nights is a web application for board game communities. It helps users organize game nights, manage attendees and waitlists, track owned games, and record play sessions and scores.
